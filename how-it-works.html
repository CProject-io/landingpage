How C-Project Works

Two mechanisms, one diagram each: what happens inside a physical node, and what changes when another blockchain's traffic — not C-Project's own — travels this network instead of the Internet.

1. Anatomy of a Node

One solar panel, one Raspberry Pi, but three services running inside a single Linux image. Select "PoG validation" below to see how the network decides whether reported energy is real.

1

Direct measurement. The sensor measures the energy generated and cryptographically signs the reading before sending it to the node's auditor.

2

Contextual estimation. The auditor cross-references the generator's GPS location and technical specs with weather data (an external oracle) to calculate how much energy it should have produced.

3

Reconciliation. If the measured and estimated values match within a tolerance band, the report is valid and paid out based on the measured value. If they don't match, it's flagged as suspicious and earns no reward.

2. Where Another Blockchain's Traffic Travels

This isn't about C-Project's own chain — it's about what happens when a node from any other blockchain uses this network instead of the Internet to talk to its peers.

3. What Is Free and What Costs Tokens

The network doesn't charge for existing; it charges for consuming another node's finite resources.

Always Free

  • Routing a message or a P2P connection through the mesh
  • Layer-0 access for any external blockchain
  • Discovery and addressing between nodes

Paid in Tokens

  • Dedicated storage for a third party's data
  • Sustained compute on a specific node
  • Guaranteed bandwidth / SLA
